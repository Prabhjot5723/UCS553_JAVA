## How to Run

1. Save the file as `Lab1.java`.
2. Open Command Prompt/Terminal.
3. Compile the program:
   ```
   javac Lab1.java
   ```
4. Run the program:
   ```
   java Lab1
   ```
5. Uncomment the required method in the `main()` function before running.

Example:
```java
obj.factorial();
```
